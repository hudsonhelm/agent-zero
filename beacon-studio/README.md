# Beacon Studio

Beacon Studio is a proposed self-hosted AI workspace and autonomous development platform. Its goal is to let a local model perform software-development work for extended periods, with cloud supervision invoked for planning, substantive review, direction, and escalation.

## Product boundary

Beacon Studio is distinct from Beacon Assistant (BAI) and Beacon Remote. Beacon Relay was proposed for communications and coordination; its functionality is intended to be integrated within Beacon Studio rather than treated as a separate product. Beacon Forge remains reserved for a possible future 3D project, and Beacon Command remains a possible later name.

## Current milestone

Evaluate unmodified, stock Agent Zero with a local model before building Beacon Studio itself or deciding whether to fork Agent Zero or integrate another execution backend. Manual cloud review and intervention are acceptable during this experiment. Do not use paid cloud fallbacks for the local capability benchmark.

See [the product brief](docs/product/beacon-studio.md) and [the stock Agent Zero evaluation plan](docs/evaluation/stock-agent-zero.md).
